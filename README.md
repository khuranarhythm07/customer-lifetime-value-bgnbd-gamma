# Customer Lifetime Value Modeling with BG/NBD and Gamma-Gamma

This repository demonstrates how to estimate Customer Lifetime Value (CLV)
using probabilistic models:

- BG/NBD (Beta Geometric Negative Binomial Distribution) for predicting purchase frequency
- Gamma-Gamma model for estimating average transaction value

## Dataset

Synthetic dataset with the following fields:

- frequency: number of repeat purchases
- recency: time since last purchase
- T: observation period
- monetary_value: average transaction value

## Workflow

1. Load transaction summary data
2. Fit BG/NBD model to estimate future purchases
3. Fit Gamma-Gamma model to estimate monetary value
4. Combine predictions to compute CLV

## Overview

Customer Lifetime Value (CLV) is a key metric used by companies to estimate the long-term value generated by customers.  
This repository demonstrates how probabilistic models — **BG/NBD** and **Gamma-Gamma** — can be used to estimate CLV using historical transaction data.

The implementation uses the Python **lifetimes** library and includes a synthetic dataset for demonstration purposes.

## Python Implementation

Example implementation using the `lifetimes` library:

```python
from lifetimes import BetaGeoFitter
from lifetimes import GammaGammaFitter
import pandas as pd

data = pd.read_csv("synthetic_clv_dataset.csv")

bgf = BetaGeoFitter()
bgf.fit(data['frequency'], data['recency'], data['T'])

predicted_purchases = bgf.predict(
    12,
    data['frequency'],
    data['recency'],
    data['T']
)

ggf = GammaGammaFitter()
ggf.fit(data['frequency'], data['monetary_value'])

predicted_monetary = ggf.conditional_expected_average_profit(
    data['frequency'],
    data['monetary_value']
)

data['CLV'] = predicted_purchases * predicted_monetary
