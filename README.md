# Customer Lifetime Value Modeling with BG/NBD and Gamma-Gamma

This repository demonstrates how to estimate **Customer Lifetime Value (CLV)** using probabilistic models.

The implementation uses:

- **BG/NBD (Beta Geometric Negative Binomial Distribution)** to estimate future purchase frequency  
- **Gamma-Gamma model** to estimate the expected transaction value

Together, these models allow us to estimate the **long-term value generated by customers based on historical transaction data**.

# Dataset

The synthetic dataset contains customer transaction summaries with the following fields:

- **frequency** — number of repeat purchases  
- **recency** — time between the first and most recent purchase  
- **T** — observation period for the customer  
- **monetary_value** — average value of the customer's transactions  

These features are commonly used in **RFM-based customer analytics**.

---

# Modeling Workflow

The CLV estimation process follows these steps:

1. Load transaction summary data  
2. Fit the **BG/NBD model** to estimate expected future purchases  
3. Fit the **Gamma-Gamma model** to estimate expected transaction value  
4. Combine predictions to compute **Customer Lifetime Value (CLV)**

CLV is calculated as:
CLV = Expected Purchases × Expected Transaction Value

# Applications
CLV modeling is widely used in industries with repeat transactions:
 - E-commerce
 - Retail companies use CLV to prioritize high-value customers and optimize marketing spending.
 - Digital Platforms
 - Media and technology companies estimate long-term engagement value for users.
